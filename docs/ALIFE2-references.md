## ALIFE 2.0 の現状との対応（Claude の見立て）

- **「部品が増えたら制御も増える」は一部すでに成り立っている。** 運動のリズム（振幅・位相・体節間の遅れ）は部品の遺伝子なので、体節や付属肢が増えればその制御も一緒に増える。足りないのは感覚と反射で、いまの脳は身体全体で 1 つ、入力 5・出力 3 の固定構造
- **局所の神経は文法と相性が良い。** 感覚→隣の体節への信号→関節や繊毛、という規則を部品の遺伝子に持たせれば、中央の脳なしで反射や協調が進化しうる
- **GPU でのシミュレーションはそのままは移せない。** ALIEN は専用の GPU 計算で、こちらはブラウザと Node で動く。先に効くのは、餌の更新の間引き、空間分割、個体ごとの並列化（Web Worker）。その先に WebGPU
- **変異率の進化、卵の大きさ**は安く入る。出生時の大きさは既に遺伝子になっている
- **溶存栄養の濃度勾配の感覚**（化学感覚）は、対照実験の後の最初の追加候補
