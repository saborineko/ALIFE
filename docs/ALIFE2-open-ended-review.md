# ALIFE2 次期統合設計案への独立レビュー

2026-11-26、v2.0.29 時点のコードと保存世界に基づく。対象は ChatGPT・Copilot・Gemini の提案を統合した「次期統合設計案（0〜14 節）」。

書き方の約束：**［実測］** は今回または過去に測った値、**［コード］** はコードを読んで確かめた事実、**［推定］** は根拠つきの見積もり、**［提案］** は私の設計案。確かめていないことは未確認と書く。

## 0. 結論

1. 統合案の方向（能力ではなく、能力が進化しうる基礎規則を足す）には同意する。ただし**順序と重点は変えるべき**だと考える。
2. いま進化を止めている天井は、提案が重視する神経系の表現力よりも手前にある。実測で確かめられたものが三つある。
   - **遺伝子が「死んだ部品」で埋まり、上限に張り付く**（§4.1）。565 世代の世界では、遺伝子の部品 12 個（上限）のうち身体に使われているのは 1 個だけだった。上限に達した後、遺伝子重複は一度も起きえない。
   - **器官の分化へ進む中立な変異経路が無い**（§4.2）。どの進化世界でも、身体は 1 種類の部品の繰り返しでできている。
   - **個体数が少なすぎて、小さな利益は淘汰にかからない**（§4.3）。数百個体では偶然が支配する。これは計算性能の問題と同じものだ。
3. 神経系の発生文法は、5 項目の中で最も大きく、必要性が最も実証されていない。**捕食の結果を見てから**、小さな対照実験で「回路構造が律速か」を先に確かめる。
4. 遺伝情報の交換は、統合案の最後ではなく**前に出す**。小さく実装でき、接触の物理をそのまま使え、個体間の関係に新しい選択圧を作る。ただし遺伝子に安定した識別子を入れるのが前提になる。
5. 保存則（Gemini）は最優先で同意する。いまのコードには、どこにも記録されないエネルギーの消失が少なくとも 5 か所ある（§3.9）。新機構を足す前に、世界全体の収支監査を入れる。
6. 捕食（身体の接触・組織の摂取・損傷）は第 1 版を実装済み。人工個体での検証結果は `docs/ALIFE2.md` に記録する。

## 3. 提案への評価・反論・修正

### 3.1 身体間の物理的相互作用（統合案 §1）

**実装済みの第 1 版**（`contact: 1`、既定は切）［コード］
- 接触：各体節を「先端に置いた円」とみなし、別の身体の円と重なると等しく逆向きの力積で押し離す。運動量は増えない（テスト済み）。
- 摂取：口が他個体の体節に届いていると、開口²・顎の筋肉に比例し、相手の装甲・外皮で減る速さで、その体節の組織を削る。消化管の空きを超えては取れない。
- 収支：食べた側の消化管に入る量は、相手が失う量（組織に残る建造費の半分＋その組織ぶんの蓄えと消化管内容）と、毎ステップ 1e-9 以内で一致する（テスト済み）。
- 損傷：体節ごとに「組織が残っている割合」を持つ。代謝・消化・生殖・蓄えの上限・口の開き・眼は器官の計算から、筋力・繊毛・パッドは物理の側で、その割合だけ落ちる。
- 修復：蓄えに余裕があれば、建造と同じ費用で最も傷んだ体節から再生する。
- 死：根の体節か、身体の 7 割を失うと「傷で死亡」。死骸は残った組織ぶんだけ粒になる。
- 定義していないもの：捕食者・被食者の種類、攻撃・逃走の本能、血縁の保護、共食いの防止。

**Copilot の Body Material モデルについて**：採用するが、軽い形にする［提案］。
- いまは定数が散らばっている（建造費は一律 10、維持費は組織別、摂取への抵抗は装甲 0.85・外皮 0.3、食物としての価値は一律）。
- これを「組織 →｛建造費、維持費、硬さ、食物としての価値｝」の一枚の表にまとめる。摂取の速さは硬さの加重平均、得られる量は価値の加重平均から決める。
- 損傷は組織別ではなく体節ごとの割合のままにする。組織別の損傷は状態が 10 倍になり、得るものが少ない。
- 「HP ではなく機能が落ちる」は既に満たしている。

**足りないもの（第 2 版）**［提案］
1. **体節の側面どうしの接触**。いまは先端の円だけなので、長い体節の途中はすり抜ける。線分どうしの距離にする。挟む・巻き付くにはこれが要る。
2. **パッドは触れた相手を掴む**。いまパッドの摩擦は底面にしか働かない。「パッドは押し付けた面に摩擦を伝える」という一つの規則にすれば、歩行と把持が同じ器官の二つの使い道になる。把持という機能は足さない。
3. **失った組織ぶんの質量を減らす**。いまは外形も質量も変わらない（物理として不整合）。
4. **体節の脱落**。組織がゼロになった体節とその先を身体から外す。成長時の作り直しと同じ処理で実現できる。自切や食いちぎりが表現できる。
5. **触覚と損傷の感覚**（§3.7）。

**反論**：統合案は「硬さ、強度、消化可能性」を並べるが、強度（壊れにくさ）と硬さ（削られにくさ）を別の量にする必要は当面ない。量を増やすほど任意の定数が増える。

### 3.2 環境の物質循環と環境改変（統合案 §2）

**評価**：方向は良いが、統合案は「物質の種類」を増やす方向に寄っている。もっと少ない規則で同じ可能性が開く［提案］。

1. **未消化分を世界に返す**。いま消化の効率（20〜90%）から漏れた分は消えている［コード］。これを身体の位置の溶存栄養に戻す。排泄物という新しい物質は要らない。
   - 効果：栄養の循環が閉じる。大きな身体のまわりが肥える。他の身体がそれを利用できる。
   - 匂いと統一できる：匂いの放出量を、この排出量に比例させる。匂いに費用を課す必要がなくなる（食べた量の副産物になる）。
2. **粒は身体に押される**。接触の物理を粒にも適用する（粒は軽いので、身体の円から押し出すだけ）。新しい遺伝子は要らない。餌を寄せる、囲う、運ぶが身体の形と動きから可能になる。
3. **食べられない粒（砂）**。エネルギー 0 で長く残る粒を、地図が供給する。押せるのは 2 と同じ。
4. **粒の密度が流れと視界を弱める**。格子ごとの「固形物の密度」から、その格子の流れと揺れを減らす（海域ごとの流れの係数は既に格子で持っている）。視覚の遮蔽も同じ密度から近似する。流体を解く必要は無い。

これで「堆積」「除去」「遮蔽」「持続する変化」が、環境側の規則三つで揃う。分泌・建築の器官は後回しでよい。

**反論**：「すべての物質を粒子にしない」に同意する。ただし格子と粒の二本立ては既にあるので、新しい表現を足す必要は無い。

### 3.3 外部記憶（統合案 §3）

**評価**：三者の提案で最も費用対効果が高い追加。既にある匂いの仕組みに、小さな規則を三つ足すだけで成立する［提案］。

1. **傷ついた組織は中身を漏らす**。組織を削られると、その量に比例して物質が水に出る。これは物理であって警報ではない。それに反応する回路が進化すれば、結果として警報物質になる（現実の魚の警報物質と同じ成り立ち）。新しい遺伝子は要らない。
2. **二つの物質の寿命を変える**。いまは両方とも毎秒 5% 消える（約 20 秒）。A を揮発性（いまのまま）、B を残留性（毎秒 0.2% 程度、拡散も遅い）にする。配分は既に遺伝するので、「長く残る痕跡を残すか」は進化に委ねられる。
3. **放出を神経で変える**。体節の信号が放出量を増減する効果器を一つ足す（§3.7）。

**反論**：「世代を超えて残る環境情報」は、物質の寿命を寿命（400〜800 秒）より長くすれば原理的に可能だが、それが役に立つには読み取る側の回路が要る。成立の判定は「痕跡を消すと行動と生存が変わるか」で行う。痕跡が残ること自体は成立ではない。

### 3.4 神経系の発生文法（統合案 §4）

**事実**［コード］
- 体節の信号は 1 つ。入力は、自分の感覚、親の信号、**子たちの信号の平均**、空腹、定数。
- 親は子の「平均」しか聞けない。左右の子の差は、親に届く前に消える。
- 一つの信号が、その体節の繊毛の強さ・旋回・関節のすべてを、固定の比で動かす。
- 左右の体節は同じ部品から作られるので、配線も同じ。

**これでできること**：左右に眼を持つ体節が、それぞれ自分の繊毛を動かす（左右の推力差で曲がる）。中枢なしの走性は表現できる。

**これでできないこと**：比較（左が右より強い）、相互抑制、離れた部位の協調、二つの感覚を別々の効果器に振り分けること。

**反論 1：神経文法が律速だという証拠はまだ無い**
- 手で配線した人工個体でさえ、味覚・匂い・視覚のどれも利益を示せなかった。
- 進化で利益になったのは繊毛（分散）と筋肉（匍匐）で、どちらも感覚を必要としない。
- つまり測れている限りでは、律速は「感じて得をする場面が無い」こと（生態）だ。統合案 §4 末尾の留保に同意し、さらに強く言う：**捕食の世界で、人工個体の感覚行動に利益が出るかを先に測る**。出なければ、文法を足しても中立に膨らむだけになる（配線保有率 100% で実測済み）。

**反論 2：神経細胞の「複製と分化」を発生過程として模擬する必要は無い**
- 身体の文法も、成長の過程を模擬しているのではなく、規則を展開しているだけだ。神経も展開で十分。

**段階的な進め方**［提案］

*段階 N1（小さな対照実験。数時間で実装できる）*
- 親が子の「差」も聞けるようにする遺伝子を一つ足す（子の信号に左右の符号を掛けて足す）。既定は 0。
- 人工個体で「左右の眼の差で餌へ曲がる」が、現行の回路ではできず、これならできるかを測る。
- 進化世界で、この遺伝子の有無によって結果が変わるかを比べる。
- これで「回路構造が律速」という仮説を、文法全体を作る前に安く検証できる。

*段階 N2（本体。N1 と捕食の結果で必要と分かった場合）*
- 部品ごとに、神経の「型」を数個まで持てる（型は部品と同じく重複・変異する）。
- 各型は遺伝する標識（2 つの数）と、入力の好み（2 つの数）、届く距離、符号、漏れ、定数を持つ。
- 結合の強さ ＝ 重み × 標識と好みの一致 × 身体の上での距離による減衰。これ一つの規則で、局所・左右・遠距離・再帰のすべてを表す。
- 感覚器と効果器も、標識を持つ節点として同じ規則でつながる。
- 費用：神経 1 個の維持、結合の強さ × **長さ**、活動。長い配線が高いので、集中化するか分散するかが淘汰の対象になる。
- 展開は身体を作るときに 1 回。結合は疎な表として持ち、弱いものは作らない。
- 計算上の上限：1 個体あたりの神経数と結合数（明記する）。

*全身の脳（3×5）と「餌の方向」の扱い*
- 新しい世界では、世界が方向を計算して渡す入力を無くす（いまの「近道を切る」）。駆動・旋回・進行方向も、最終的には神経の出力に置き換える。旧方式は選択式で残す。

### 3.5 神経可塑性（統合案 §5）

**Gemini の指摘は、いまのコードで既に起きている**［コード］
- 成長の一段ごとに身体を作り直しており、そのたびに体節の信号と感覚の順応の記憶は初期化される。保存・復元では保たれるが、成長では失われる。
- 今回入れた損傷も体節の番号で持っている。成長で体節数が変わる身体では、対応がずれうる。

**したがって先に要るもの**［提案］
- 体節（と将来の神経）に、**発生上の住所**（どの部品の、どの繰り返しの、どの対称コピーか）を与え、状態はすべて住所で引く。成長・損傷・修復・保存・両親からの組み換えが、同じ鍵で整合する。
- これは可塑性だけでなく、損傷、遺伝子の交換（§3.6）にも必要な共通基盤だ。

**規則**（N2 の結合ができてから）
- 結合の変化 ＝ 学習率 ×（前と後の活動の積、前だけ、後だけ、の重み付き和）× 調節 − 忘却率 ×（遺伝的な初期値からのずれ）。
- 調節は、身体の内部の物理量（蓄えの増減、組織の損失、消化管の満ち具合）に遺伝する係数を掛けたもの。係数は 0 にもなれる。
- 「人間が報酬を与えない」との関係：内部の物理量は報酬ではない。どれを「良い」とみなすかは遺伝子が決める。ここは明示しておくべき設計判断だ。
- 費用：可塑的な結合の維持（学習率に比例）と、変化量に比例する費用。
- 継承：学習した結合は子に渡らない。渡るのは初期値と規則の係数だけ。

**成立の前提（統合案に欠けている点）**
- 学ぶ価値のあるものが世界に無ければ、可塑性は費用だけなので 0 へ進化する。いまの世界は、一生（400〜800 秒）のうちに規則が変わる出来事がほぼ無い。
- 前提になる候補：潮（以前に合意）、捕食者と被食者の色や匂いが地域と時期で変わること、残留する痕跡。

**対照実験**
| 区別したいもの | 操作 |
|---|---|
| 信号の残留 | 活動だけを初期化（結合は残す） |
| 感覚の順応 | 順応の記憶だけを初期化 |
| 生涯学習 | 学習率を 0 に固定／学習済みの結合を初期値に戻す |
| 遺伝的適応 | 別の海域で生まれた系統の子を移して育てる（行動が育ちに従えば学習、血筋に従えば遺伝） |

### 3.6 遺伝情報の交換（統合案 §6）

**事実**［コード］：`crossover` は部品と接続を**番号順**に突き合わせ、遺伝子ごとに半々で混ぜる。世界は呼んでいない。

**問題**：重複や削除で番号がずれた相手と混ぜると、対応しない遺伝子どうしが混ざる。

**提案**
1. 部品と接続に、遺伝する識別子を持たせる（重複したら新しい番号）。組み換えは識別子が一致するものどうしだけで行う。一致しないものは産む側のものを使う。
   - 副産物：遺伝的に離れた相手とは混ざる部分が減る。種の定義を入れなくても、交配の隔たりが自然に生じる。
2. 経路は接触。熟した卵を持つ身体が、生殖組織を持つ他個体に触れていると、卵が相手の遺伝子を受け取る。受け取る確率は遺伝する（0 なら従来どおりの単為生殖）。
3. 性は定義しない。全個体が渡す側にも受け取る側にもなれる。
4. 渡す側にも小さな費用を課す（収支のため）。
5. 系譜：産んだ親はこれまでどおり、もう一方の親を別に記録する。祖先をたどる表示は「産んだ親の系列」を主にする。

**順序についての反論**：統合案は最後に置くが、前に出す。理由は三つ。
- 実装が小さい（識別子＋接触の検出の再利用＋既存の組み換え）。
- 個体間に「触れる理由」を作る。捕食と対になる関係になる。
- 配偶子の放出と融合（大小の配偶子の分化）は、これが成立してから。最初から入れるのは過剰。

**予測**（結果の前）：受け取る確率は、いまの変異の大きさでは下がる方向へ進化する可能性が高い（60%）。組み換えの利益は、有害な変異の蓄積や、変わり続ける相手（捕食者）がいて初めて出る。

### 3.7 感覚器と効果器（統合案 §7）

**同意**。ここは小さく足せて、効果が大きい。接触の第 2 版と一緒に入れるべきだ［提案］。

*感覚（すべて「その体節の位置の物理量を一つ測る」原則どおり）*
- 触覚：その体節が受けた接触の力積。
- 損傷：その体節が失っている組織の割合と、いま削られている速さ。
- 関節角：自分の関節の曲がり。
- 遮蔽：視野の途中にある身体と固形物（§3.2 の密度）で、見える量を減らす。

*効果器*
- **口の開閉**。いま口は触れたものを必ず削る。だから「血縁を食わない」は、触れない以外に進化しようがない。開閉を信号で変えられれば、共食いの回避は定義せずに進化の対象になる。
- パッドの押し付け（いまは律動だけで決まる）。
- 物質の放出（§3.3）。
- 産むタイミング（いまは蓄えが閾値を超えると自動）。

**限界**：体節の信号が 1 つなので、効果器を足すほど「一つの信号で全部が動く」制約がきつくなる。これが N2（体節あたり複数の神経）を必要とする最初の具体的な理由になる。

### 3.8 社会性（統合案 §8）

同意。判定は「他個体の情報を切ると行動が変わり、その差が生存か繁殖に効く」に限る。利益の水準（個体・血縁・集団）の区別は、系譜の記録から血縁度を計算できるので実行可能だ。

### 3.9 保存則（統合案 §9）

**いまのコードにある、記録されないエネルギーの消失**［コード］
1. 蓄えが上限を超えた分は切り捨てられる。
2. 消化の効率から漏れた分（10〜80%）は消える。
3. 死骸になるとき、建造費の半分が消え、残り（と蓄え・消化管の内容）のさらに半分が消える。
4. 死んだ個体の成長用の積立と作りかけの卵は、死骸に含まれず消える。
5. 産むときの固定費（1 個あたり 0.4）は消える。
6. 匂いの放出は無料。

これらは「熱として世界の外へ出た」と解釈すれば矛盾ではない。問題は、**どこにも数えられていない**ことだ。数えていないものは、新機構を足したときに二重計上や無限増殖が紛れても気づけない。

**提案**：世界全体の収支監査を入れる。
- 流入（降ってくる粒、溶存栄養の回復）、貯蔵（溶存栄養、粒、身体の蓄え・消化管・積立・卵・組織）、散逸（上の 1〜5 と代謝）を毎ステップ足し合わせ、流入 − 散逸 − 貯蔵の増加 ＝ 0 を確かめる。
- 道具とテストの両方にする。以後、新機構はこの監査を通ることを受け入れ条件にする。

**実装間の干渉**：最も危ないのは「作り直し」だ。成長・損傷・修復・学習・組み換えのすべてが、体節の同一性に依存する。住所（§3.5）を先に入れることで、まとめて防げる。

## 4. 提案に含まれていない根本的な制約

### 4.1 遺伝子が死んだ部品で埋まり、上限に張り付く［実測］［コード］

- 変異には「部品の重複」（7%）と「接続の削除」（2%）があるが、**部品の削除は無い**。
- 重複で増えた部品は、接続が消えると根から到達できなくなる。身体には現れないが、遺伝子には残り続ける。
- その結果、部品数は増える一方になる。565 世代の系統では、236 世代で上限 12 に達し、以後 330 世代そのままだった。12 個のうち使われているのは 1 個。
- **上限に達すると、重複は起きない**。重複は新しい器官が生まれる主な経路なので、この系統は 236 世代以降、その経路を失っていた。
- 「上限を撤廃する」では解決しない。死んだ部品が無限に増えるだけだ。

**提案**：上限は「使われている部品」に対して数える。到達できない部品は、一定の確率で消える（偽遺伝子の崩壊）。乱数の使われ方が変わるので、選択式にして既存の世界は変えない。

### 4.2 器官の分化へ進む中立な経路が無い［実測］［コード］

- 6000〜30000 秒の進化世界では、使われている部品は平均 1.1〜1.4 個。565 世代でも 1 個。
- つまり多体節の身体は、**同じ組織配分の体節の繰り返し**でできている。頭・胴・尾のような分化は起きていない。
- 理由：重複した部品は、ランダムな角度の側枝として生える。見た目が大きく変わるので、多くは不利になって消える。
- 現実の進化で分化の主な経路になっている「同じものを繰り返す → 一部が別のものに変わる」に相当する変異が無い。

**提案**：「鎖の分割」という変異を足す。繰り返しの鎖の途中から先を、元の部品の**複製**に置き換える。その瞬間は身体がほとんど変わらない（中立）。その後、複製の側だけが変異していける。

これは 5 項目のどれよりも安く、身体の分化という最初の目標に直接効く可能性がある。対照実験：この変異の有無で、「使われている部品の数」と体制の種類が変わるか。

### 4.3 個体数が少なく、小さな利益は淘汰にかからない［実測］［推定］

- 個体数は 100〜500。この大きさでは、利益が 1/個体数（0.2〜1%）より小さい形質は、偶然に埋もれる。
- 実際、同じ条件でも世界ごとの結果のばらつきが大きく（体制の実効的な種類数 2.3〜12.2）、ユーザーの世界は 20〜40 個体まで減って、ほぼ確実な絶滅に至った。
- 神経や感覚の初期の利益は小さいはずだ。**数百個体では、それが有利でも広がらない**。
- これは「計算性能」（統合案 §11）と同じ問題で、後回しにできる付帯事項ではない。

### 4.4 変異の量が遺伝子の大きさに比例する［コード］、ただし害は未確認［実測］

- 1 回の変異で変わる遺伝子の期待数は、遺伝子の大きさに比例する（9 → 84）。
- 理屈の上では、大きな遺伝子ほど子が壊れやすく、維持できる複雑さに上限ができる。
- しかし実測では、遺伝子が大きい系統で子の壊れやすさが増えている証拠は無い（1 回の変異で体節数か体積が大きく変わる割合は、部品 6 個以上の遺伝子で 35%、部品 1〜5 個の遺伝子で 40〜57%）。大きな遺伝子の中身がほとんど死んだ部品だったためと考えられる。標本も小さい（4 個体）。
- 結論：**疑わしいが、実証していない**。4.1 を直して使われる部品が増えたときに、改めて測る。
- 変異率そのものを遺伝させる（進化可能性の進化）のは安い追加で、そのときの対照になる。

### 4.5 生活史が一本道［コード］

- 成長は、同じ身体を大きくするだけ。幼体と成体が別の身体を持つこと（変態）は表現できない。
- 接続の発現範囲は、身体の軸に沿ってしか指定できない。成長段階に沿った範囲を足せば、幼体だけの器官・成体だけの器官が表現できる。既存の概念の一般化で済む。

### 4.6 環境が時間的に単調［コード］

- 粒は一定の率で降り、流れは周期的だが、資源の増減や危険の周期が無い。予測や記憶が役に立つ構造が無い。可塑性（§3.5）の前提として効く。

### 4.8 進化的足場の監査（最終稿 §10 への回答）

足場を「途中の段階が、中立か、小さくても利益があること」と定義する。報酬や生存の補正は足場ではないので入れない。不利な変異も絶滅も、そのまま起きさせる。

各能力について、最初の一歩から利益が出るまでの道を調べた。

| 能力 | 最初の一歩 | 途中段階の損得 | 足場の評価 |
|---|---|---|---|
| 繊毛で動く | 繊毛の遺伝子 1 つ | すぐ動ける。維持費は小さい | あり（進化で獲得済み） |
| 筋肉と関節で動く | 体節 2 つ以上＋筋肉＋律動の振幅 | 44 世代で出現、利益が出たのは約 200 世代から［実測］ | 細い（長い中立〜不利の区間を偶然で越えた。1 世界のみ） |
| 味覚・匂いで応じる | 配線の遺伝子 2 つ（感覚→信号、信号→繊毛） | 器官が要らないので費用はごく小さい | 材料はある（配線は中立に広がる）。利益が無いだけ |
| 眼で応じる | 眼の組織＋眼からの配線＋効果器への配線の 3 つ | 眼の組織だけだと維持費だけがかかる（収支 0.068→0.048）［実測］ | **谷がある**。6000 秒の 12 世界で眼を持つ個体は 3〜7%［実測］ |
| 他個体の組織を得る | 無し（口は既にある） | 密集すれば最初から収入の 0.4〜4% になる［実測］ | あり。跳躍は要らない |
| 装甲で守る | 装甲の遺伝子 1 つ | 維持費は小さい。削られる速さがすぐ落ちる | あり（ただし削る相手が稀なうちは費用だけ） |
| 器官の分化 | 部品の重複 | 重複は側枝として生え、形が大きく変わる | **無い**（§4.2）。「鎖の分割」で中立な一歩を作る |
| 遺伝子の重複そのもの | — | 上限に達すると不可能 | **途中で閉じる**（§4.1） |
| 遺伝情報の交換（提案） | 受け取る確率の遺伝子 1 つ | 相手は特別な遺伝子を要さない | あり（一歩で成立する設計にできる） |
| 可塑性（提案） | 学習率の遺伝子 | 学習率を上げた瞬間に費用が出る | 谷になりやすい。学ぶ価値のある変動が先に要る |

**見えてきた型**
- 「新しい組織が要り、その組織に維持費があり、配線が揃うまで何の役にも立たない」能力は谷を持つ。眼がその例。
- 谷を埋める正当な方法は、報酬ではなく、**その組織に最初から小さな別の使い道があること**。現実の眼も、像を結ぶ前から明暗に反応する役に立っていた。いまの眼は、古い方式（全身の感知半径）では配線なしで働くが、新しい方式では配線が要る。
- ただし「古い近道が眼の足場になっている」という証拠は無い。眼を持つ個体は、近道ありで 3.2% [0〜5.5%]、近道なしで 7.4% [2.9〜11.2%] で、範囲が重なる［実測］。
- 既定値が 0 の遺伝子を足すときは、毎回「最初の一歩で費用だけが出ないか」を確かめる。これを受け入れ条件に加える。

### 4.9 これらを全部入れても、依然として不可能なこと

開放型進化の成立を前提にしない、という最終稿の末尾に答える。次のものは、提案をすべて実装しても起きない。

- **新しい種類の組織や器官**。組織は固定の一覧（筋肉、神経、消化管、管、生殖、蓄え、眼、装甲、口、外皮、繊毛、パッド）で、進化はその配分と配置しか変えられない。既存の組織に新しい使い道が生まれることはあっても、新しい物理を持つ器官は生まれない。
- **新しい感覚の種類**。感じられるのは、世界が物理として持っている量だけ（溶存栄養、2 種類の物質、色と見かけの大きさ、追加すれば接触・損傷）。音、電場、温度のような量は、世界に無い限り感覚にもならない。
- **代謝そのものの進化**。エネルギーは一種類の量で、何を食べられるかは口の大きさだけで決まる。別の物質を利用する代謝経路、毒、消化酵素の進化は表現できない。
- **物質 2 種類を超える通信**。信号の語彙は、物質 A・B の量と色に限られる。
- **3 次元の身体と、細胞の水準の発生**。
- **計算上の上限を超える身体**。体節の数には上限が要る。

これは「だから無意味だ」という話ではない。可能性の空間を広げることはできるが、**無限にはならない**。到達点は「人間が個別に設計していない組み合わせが、長く現れ続けるか」であり、それは §4.7 の記録で測る。頭打ちになったら、そのとき律速になっている天井を、同じ方法（実測で特定する）で探す。

### 4.10 最終稿の補足 3 点について

| 補足 | 回答 |
|---|---|
| 進化的足場に人工的な報酬を与えない | 同意。足場は「中立な一歩が存在すること」として作る（鎖の分割、識別子による組み換え）。生存の補正は入れない。捕食の世界が崩れても手を入れない |
| 神経の同一性は、固定 ID の排除ではなく安定した識別方法で | 同意。§3.5 の「発生上の住所」（どの部品の、何番目の繰り返しの、どの対称コピーか）がそれに当たる。番号ではなく文法の展開経路なので、成長で体節が増えても既存の体節の住所は変わらない。損傷・学習・組み換えが同じ鍵を使う |
| 少ない規則で最大の可能性を | 同意。このレビューで足す規則を数えると、環境側 4（未消化分の還元、粒は押せる、砂、密度が流れと視界を弱める）、身体側 3（側面の接触、パッドは触れた面を掴む、傷は中身を漏らす）、遺伝子側 3（死んだ部品の崩壊、鎖の分割、識別子による組み換え）。新しい器官は 0。神経の文法と可塑性だけが大きく、それは必要が示されてからにする |

### 4.7 進化が開いているかを測る物差しが無い

- 統合案は「予想していなかったものが獲得され続けるか」を基準にするが、それを測る記録が無い。複雑さの量で測らない、という点には同意する。
- **提案**（報酬ではなく記録として）：
  - 一定世代以上続いた体制の累積数（増え続けるか、頭打ちになるか）。
  - 誰が誰の組織を得たか（体制どうしの行列）。食う・食われるの網ができるか。
  - 使われている部品の数、切断すると行動や生存が変わる配線の数。
  - 絶滅した機能の再獲得（既に系譜の解析でやっている）。

## 5. 依存関係と推奨順序

```
基盤 A（住所・識別子・収支監査）───┬──> 接触 第2版（把持・触覚・脱落）
                                   ├──> 遺伝情報の交換
                                   └──> 可塑性（N2 の後）
基盤 B（遺伝子の詰まりの解消・鎖の分割）──> 身体の分化（単独で試せる）
基盤 C（個体数：並列の島）────────────> すべての長期実験
接触 第1版（済）──> 捕食の進化試験 ──> 「感覚に利益が出るか」の判定 ──> N1 ──> N2 ──> 可塑性
未消化分の還元 ──> 匂いの費用の統一 ──> 傷からの漏出・残留性の物質（外部記憶）──> 押せる粒・砂
```

| 順 | 内容 | 大きさ | 理由 |
|---|---|---|---|
| 1 | 捕食の進化試験（摂取あり／摂取を切った対照、各 4 世界） | 計算のみ | 実装済み。以後の判断の材料になる |
| 2 | 基盤 B：遺伝子の詰まりの解消と「鎖の分割」（選択式） | 小 | 実測で確かめた天井。5 項目より安い |
| 3 | 基盤 A：収支監査、体節の住所、遺伝子の識別子 | 中 | 以後の全項目の前提。干渉を先に潰す |
| 4 | 基盤 C：並列の島（複数プロセスの世界のあいだで個体を移す） | 中 | 保存と移住の仕組みを再利用できる。物理を変えない |
| 5 | 接触 第 2 版＋触覚・損傷の感覚＋口などの効果器 | 中 | 捕食を「行動で応じられるもの」にする |
| 6 | 遺伝情報の交換 | 小 | 3 と接触があれば小さい |
| 7 | 未消化分の還元、傷からの漏出、残留性の物質 | 小 | 外部記憶の最小形。循環が閉じる |
| 8 | N1：左右差の対照実験 | 小 | N2 が要るかの判定 |
| 9 | N2：神経の文法 | 大 | 8 と 1 の結果次第 |
| 10 | 押せる粒・砂・遮蔽 | 中 | 接触の再利用 |
| 11 | 可塑性、潮 | 大 | 9 と時間変動が前提 |

統合案の暫定順（1 捕食 → 2 環境 → 3 神経 → 4 可塑性 → 5 遺伝）との違いは、基盤 A〜C を前に置くこと、遺伝情報の交換を前に出すこと、神経の文法を判定の後ろに下げること。

**判断の分岐点**
- 捕食の世界で、人工個体の感覚行動（逃げる・追う）に利益が出ない → 神経より先に、生態の側（密度、隠れ場所、時間変動）を見直す。
- 「鎖の分割」で使われる部品が増えない → 分化の律速は変異経路ではなく経済（維持費）にある。
- 並列の島で個体数を 4 倍にしても結果のばらつきが減らない → 律速は個体数ではない。

## 7. 計算負荷

**現状**［実測］：約 280 個体で CPU 1 秒あたり世界の約 3 秒。1 世代（約 250 秒）に約 75 秒。接触で +15〜50%。

**目標との距離**［推定］：5000 個体 × 1000 世代は、いまの速さだと単一コアで約 15 日。現実的にするには 20〜50 倍が要る。

**打ち手**（効果が大きく、物理を変えない順）
1. **並列の島**。世界を複数プロセス（ブラウザではワーカー）に分け、一定間隔で個体を移す。コア数に比例して個体数が増える。物理は変わらないので、結果が意図せず変わる危険が小さい。構造化された集団は多様性の維持にも向く。
2. **描画とシミュレーションの分離**（ブラウザ）。描画が計算を止めない。
3. 実測で重い箇所から順に直す。前回の計測では物理と粒の更新が主だった。今回は内訳を測り直していない（未実施）。
4. 動かない身体の計算の省略は既にある。接触の世界ではこれを切っているので、「誰にも触れておらず自分でも動かない身体」だけ省略を戻す。
5. 神経 N2 は疎な結合表にする。1 個体あたりの結合数に上限を置く。
6. GPU・WASM は最後。書き直しの費用が大きく、検証が難しい。

**高速化の検証**：以前、粒の揺らしを間引いただけで採食が 15% 落ちた。速くする変更は毎回、複数の世界で結果の分布を比べ、ばらつきの範囲内であることを確かめてから採用する。

**保存容量**：絶滅した体制の遺伝子の間引きは実装済み。両親のある系譜、神経の結合、学習状態で 1 個体あたりの保存量が増える。島ごとに分けて保存する。

## 8. 対照実験と成立判定

統合案 §12 の表に同意する。追加と修正を挙げる。

| 対象 | 対照 | 成立の基準 |
|---|---|---|
| 組織の摂取 | 摂取を切る（接触は残す）。実装済み | 摂取で主に暮らす系統が、複数の世界で 50 世代以上続く |
| 防御 | 装甲・外皮の軽減を無効化 | 摂取ありの世界で装甲が増え、無効化すると増えない |
| 逃げる・追う | 触覚・視覚・匂いを個別に切断 | 切ると被食率か摂取量が、世界間のばらつきを超えて変わる |
| 鎖の分割 | その変異を無効化 | 使われている部品の数が増える |
| 遺伝情報の交換 | 受け取る確率を 0 に固定 | 受け取る確率が 0 へ崩れずに維持される。環境を変えたときの回復が速い |
| 外部記憶 | 物質を消去／残留性を無くす | 消すと行動と生存が変わる |
| 神経 N1 | 差の入力を 0 に固定 | 人工個体で差が出る。進化世界で使われる |
| 可塑性 | §3.5 の表 | 学習率を 0 にすると、変わる環境での生存が落ちる |
| 個体数 | 島の数を変える | 世界間のばらつきが減る |

**共通の規則**（これまでの合意どおり）
- 予測と基準は結果の前に固定する。探索的な試験と確認試験を分ける。
- 「同じ乱数種の対」は対照にならない。同じ保存世界から乱数だけ変えた複数本で、ばらつきを先に測る。
- 差が検出できないことと、影響が無いことを区別する。

**統合案への修正**：「対応する乱数種を用いた分岐比較」は、そのままでは不十分。規則を変えると乱数の使われ方が変わり、同じ乱数種でも別の歴史になる。対にするのは保存世界（出発点）であって、乱数種ではない。

## 9. 既存世界との互換性と再現性

- 新しい規則はすべて選択式で、既定は切。匂い・視覚・なだらかな境界・接触の 4 つとも、切の世界が変更前と完全に一致することを毎回確かめている。同じ方式を続ける。
- 新しい遺伝子は、その規則が有効な世界でだけ変異し、切の世界では乱数を消費しない。
- 走っている世界に途中から足す仕組み（`World.enable`）は、接触にも対応済み。
- 例外になりうるもの：遺伝子の識別子と体節の住所は、保存形式に項目が増える。古い保存は読めるようにする（読み込み時に番号を振る）。
- ユーザーが最初から走らせている世界（捕食なし）は、そのまま比較対象として維持できる。
