## 2. なぜ旧方式を延長しなかったか

ALIFE 23 の遺伝子は `plan = [親細胞, 角度, 種類, 接続長]` の列で、細胞を1個ずつ直接配置する。
この形式では「体節を1つ増やす」「脚を対で増やす」が数十個の遺伝子の同時変化を要し、描画も細胞の円を並べる以外にない。
上限が低いのは実装量ではなく符号化の問題と判断し、発生・物理・描画を別系統で書いた。

## 3. 設計上の決定

### 遺伝子：グラフ文法による間接符号化（`alife2-genome.js`）
- `parts`: 身体の一部の雛形（長さ・太さ・厚さ・筋肉・外皮・外骨格・関節可動域・局所リズム・器官）
- `links`: 「部品Aが部品Bをここに生やす」生成規則。対称性（なし／鏡像／放射n）、再帰回数 `repeat`、体軸上の発現窓 `lo..hi`、リズムの位相差を持つ
- 自己リンク（A→A）が体節の反復を作る。発現窓が「頭は先頭だけ」「脚は前半だけ」「尾は末端だけ」を決める（Hox 的）
- 「脚」「尾」「頭」という語はエンジン内に存在しない。規則が作った結果を観察者がそう呼ぶだけ
- 検討した他方式: 直接符号化（旧方式。却下）、遺伝子制御ネットワーク（表現力は高いが形態上限の実証に時間がかかるため後回し。文法の発現窓を濃度勾配に置き換える形で将来導入可能）

### 発生（`alife2-development.js`）
- 文法を幅優先で展開して体節の木（body plan）を作る。上限160体節
- `stage` 0→1 で芽から成体へ。後から生まれる体節ほど遅れて伸びる

### 身体物理（`alife2-physics.js`）
- 体節＝長さ一定の剛体棒。各体節は遠位端の質点1個を持ち、近位端は親の座標系に固定された点（質点の複素重み和）。付着が厳密で、運動量・角運動量を保存する
- 筋肉＝関節角への柔らかい拘束（XPBD）。力の上限は筋肉量×断面で決まる。子と親に等大逆向きに働くので、**筋肉だけでは重心は動かない**
- 水＝体節の横方向の動きに強く、軸方向に弱く抵抗する（抵抗力理論）。横抵抗は厚さ方向の面積に比例
- 底面＝押し付けられた接地パッドだけが摩擦を持つ。パッドが支えきれない体重は腹で引きずる
- **速度を与える変数は存在しない**

### 運動制御（`alife2-neural.js`）
- Phase 1 は関節ごとの局所振動子（振幅・位相・体節間の位相遅れ・打ち戻しの速度差・接地タイミングが遺伝子）
- `cmd = {drive, turn, heading}` が Phase 2 で脳が握る入力口。今は実験者が与える

### 描画（`alife2-render.js`）
- 各体節を先細りカプセルの距離場とし、同じ鎖の中は厳密な和、鎖どうしは滑らかな和で結合。これを厚みの高さ場として陰影・半透明化する
- 器官（筋繊維・消化管・神経索・生殖腺・眼）は同じ body plan から外皮の下に描く。体表の顆粒・環状紋は身体に固定された座標で生成
- スプライト・固定画像・種別ごとの描画コードは無い。5系統の違いは数値だけ
- 外皮は WebGL2（`alife2-gpu.js`、場の計算→陰影の2パス）で描く。同じ方式の CPU 実装が基準実装兼フォールバックで、Node 上でも画素を計算できるのでテストで描画を検証できる
- GPU 版だけの追加表現：クチクラの薄膜干渉色、2灯の反射。器官と体表構造は両方とも Canvas 2D

### 実験室の設計器（`alife2-bodyplan.js`）
- スライダーの値を遺伝子（文法）に書き換えるだけ。身体・運動・描画は進化個体と同じコードを通る

- `sheet.png` — パラメーターの連続変化、発生段階、突然変異体
- `motion-tail-0..3.png` — 同一個体の連続する4時点（身体が変形している）

テスト（13件、全通過）が確認していること:
- 5系統は構造が互いに異なり、同じ遺伝子は同じ身体になる（遺伝）
- パラメーターで形が連続的に変わる。発生段階で体節が増える
- 変異した遺伝子は実際に発生し、物理が破綻しない
- **真空では関節が曲がっても重心は動かない**（全5系統、移動 < 1e-6）
- 筋肉ゼロ・活動ゼロでは進まない
- **脚があるだけでは歩けない**：パッド無し、または接地タイミングが合わないと速度は半分未満
- 打ちと戻しが時間対称な腕では泳げず、非対称にすると泳げる（放射型）
- 鰭の有無・波数で速度と移動コストが変わる
- 姿勢と形が変わると描画の画素が変わる

実測で分かった予想外のこと:
- 歩行の最適な接地位相は理論値（90°）ではなく 180° 付近だった。関節が指令に約1/4周期遅れるため。歩容は身体に合わせて調整される必要がある（＝進化・学習の対象になる）
- 放射型は底面を這う設定ではほぼ進まず、泳ぐ方が成立した。それでも 0.026 体長/s と遅い

## 5. Phase 2：代謝と世界（`alife2-organs.js` `alife2-engine.js`）

### 方針
複雑さ・大きさ・運動への報酬は一切無い。代わりに全部に値段を付け、身体によって違う生活が成り立つようにした。

| 仕組み | 効果 |
|---|---|
| 体表からの溶存栄養の吸収（表面積比例、局所的に枯渇） | 小さい身体の生活。密度に上限 |
| 粒状の餌（大きいほどエネルギーは体積比例、口の開きを超えると食えない） | 太い頭・大きい身体の生活 |
| 粒は移動する集中域に偏在。底面帯は流れが無く粒が固定 | 運動・感覚・接地の生活 |
| 一つの体節に入る組織量に上限（筋・消化・生殖・貯蔵・神経・輸送の合計 1.5） | 単体節は全部を少しずつ、多体節は部位ごとに特化 |
| 消化管から遠い体節は供給が落ち筋力が下がる。輸送組織で延ばせるが維持費がかかる | 大きい身体の内部構造 |
| 全組織・体表に体積／面積比例の維持費、筋仕事はエネルギー消費 | 無駄な器官は損 |
| 貯蔵量は体積と貯蔵組織に比例 | 大きい身体は飢えに強い |
| 出生時の大きさが遺伝子（大きい子は1匹あたり高い） | r/K 的な生活史 |
| 個体ごとの固定費（維持・複製） | 身体を無限に小さくできない |

### 進化試験が早期に暴いた設計の誤り（全部、実際に出た）
1. **幼体が永久に育たない**：成長1段の費用が幼体の貯蔵上限を超えていた → 成長用の積立を導入
2. **極小の吸収体が上限まで埋め尽くす**：個体数が資源ではなく人工の上限で頭打ちだった → 溶存栄養を薄くして資源律速に
3. **体積ほぼゼロの「塵」**：小さいほど維持費が消える → サイズ非依存の固定費を導入
4. **餌の配分の実装誤り**：エネルギー配分のつもりが個数配分で、小粒がほぼ無かった
5. **泳いで食う生活が最初から赤字**：人工の遊泳体を入れて収支を測ると、摂取が維持費の数十分の一だった → 粒のエネルギー密度を上げた
6. **出生が止まるとエネルギーが漏れる**（会計の不具合。保存則テストで発見）

| 遊泳・眼なし | 1.47 | 0.241 | 0.030 | 0.244 | +0.026 | 7/12 |

- **大型化は不成立**：維持費は体積に比例して増えるのに、摂取はほぼ増えない。消費を一律に下げる解決はしていない

`docs/alife2/evolved.png` が終了時に多かった体制。**予想していなかった結果**：身体は多体節化したが動物にはならず、**口を複数持つ動かない捕食者**になった（seed 1 は口3〜4個の裂片状、seed 2 は口を最大64個並べた塊と柄のある形）。粒が沈降・拡散して勝手に当たるので、泳ぐより口を増やして待つ方が安い。固着性の懸濁物食者に相当する。

### 人工遊泳体の定着試験（`tools/alife2-invade.js`、変異なし）
原始個体の世界に眼のある人工遊泳体15匹を放つ。
- 小さく産む（出生段階0.3）：45匹まで増えるが、子は口が最小の粒より小さくて食えず、泳がない吸収体として停滞（速度 0.29 → 0.02）
- 大きく産む（0.7）：泳ぎ続けるが 23匹 → 4世代目で 2〜3匹

**結論：この経済では「泳いで食う生活」は存在はするが、待ち伏せ・吸収に競り負ける。** 動物が進化しないのは遺伝子構造の問題である前に、世界の側が動物を必要としていない。

### 観察と記録（`alife2-world.js`、世界側は `alife2-engine.js`）
ALIFE 23 にあって 2.0 に無かった観察機能のうち、未実装の生物学に依存しないものを入れた。
- **系譜**：全個体の親・系統・世代・出生／死亡時刻・死因・体制・遺伝子を記録。生存個体とその祖先だけを残し、子孫の絶えた枝は除く。観察個体から始祖まで、体制が変わった世代を身体つきで辿れる。CSV 出力
- **生きている形態図鑑**、**生存個体 TOP 10**、**進化の記録**（初の多体節・複数の口・眼・動く関節、最大の更新、系統の絶滅）、**履歴グラフ**、追跡
- **保存・読み込み**：JSON ファイルと端末への自動保存（`alife2_world_v1`。ALIFE 23 の `alife05-observatory` / `alife16_*` とは別）。復元時、関節の姿勢は休止位置から再開する
- まだ無いもの：島ごとの移住、巣、社会・闘争の観測、神経回路の表示、世代別バックアップ（対応する仕組み自体が 2.0 に無い）

- **体制の記録（絶滅系統を含む）**：新しい体制が生まれた個体を起点に、代表遺伝子・体制・出現と絶滅の時刻・個体数・世代数・死因・死んだ個体の平均（寿命、口からの収入、自力移動）を残す。絶滅しても消さない（容量のため 4000 件を超えたら2匹以下で絶えた記録から省く）。個体単位の系譜は、生存個体とその祖先だけを残す

### 繊毛（`cilia` / `beat` 遺伝子）
見た目のためではなく器官として入れた。体表の繊毛は面積に比例した推進力を水に対して出し（真空では出ない）、拍動した分だけエネルギーを使う。絵の繊毛の波は実際の拍動の向きと強さ（遺伝子 `beat` × 脳の `drive`）で動く。
- 実測：繊毛 0.2 / 0.5 / 1.0 の単体節は 0.28 / 0.50 / 0.75 u/s。体積 37 の大きい身体では 0.09 u/s（大きい身体は繊毛では進めない＝筋肉が要る）
- **今の世界では元が取れない**：繊毛で 0.4 u/s 泳ぐ単体節の摂取は 0.028〜0.044/s（動かない個体 0.030）、拍動費 0.021/s の分だけ収支が悪い。粒の揺らぎと沈降が、待つ側にも同程度の遭遇を与えているため

### 対照実験：繊毛あり／なし（seed 11〜14、各 6000 秒）— 予測を結果の前に固定
同じ乱数種・同じ時間で、繊毛の遺伝子が発現できる世界と、できない世界（`noCilia=1`）を対にする。
測るもの：自力移動、体節数、口の数、眼、**走性指数**（餌を知覚した時の方向へ、次の瞬間に自力でどれだけ進んだか。−1〜1、舵を切らなければ 0。テストで 0 と 0.25 超を確認済み）。

結果を見る前の予測（Claude、2026-11-25）：
- P1 繊毛ありで自力移動（平均 0.05 u/s 超）が生じる：4 シード中 3 以上（確信 75%）
- P2 走性指数が 0.1 を超えるシードが 1 つ以上：50%。眼を持つ個体が 20% を超えるシードが 1 つ以上：25%

- 影響を受けない結論：繊毛による能動的な移動、多体節化の抑制（P3）、固着型との共存（P4）
- 教訓：census の `taxis` は「進行方向と知覚方向の相関」にすぎない。今後、行動の進化は**切断対照との差**で判定する。指標の値だけでは主張しない

### 神経系の実装方針（2026-11-25 に合意。対照実験の完了後に着手）
実装上の順序案であり、進化にこの順番を強制するものではない。

3. **再帰回路** — 神経信号が過去の状態を保持する。体節ごとの信号を「漏れのある状態」にし、自己結合と減衰の速さを遺伝子にする。刺激が消えても反応が続く、同じ刺激でも直前の経験で反応が変わる、外部刺激なしに内部活動で動き出す、が個別実装なしに獲得可能になる
4. **神経可塑性** — 生きている間に結合の強さが変わる。学習率と規則の形を遺伝子にする
5. **神経系の構造進化** — 神経細胞数・接続・学習特性そのものが進化する

### 局所神経回路と化学感覚（v2.0.14、`alife2-neural.js` の `local`）
実装した。**ただし、手で設計した回路では、味覚を切った対照に対する利益は確認できなかった。**

仕組み：
- **感覚は体節ごと**：各体節が、自分の位置の溶存栄養の濃さだけを感じる（格子の値を補間。濃い方向は与えない）。感度は神経組織の量に比例
- **回路は部品の遺伝子**：信号 ← 信号 + leak ×（tanh(nC×感覚 + nP×親の体節の信号 + nK×子の体節の信号 + nH×空腹 + nB) − 信号）。体節が増えれば回路も増える
- **出力は自分の体節へ**：繊毛の強さ（mCil）、繊毛の左右差＝旋回（mTurn）、関節の曲げ（mJoint）
- **過去を持てる**：`leak` が 1 なら毎回作り直す（反射）、小さくすると過去を引きずる（再帰）。`adapt` を上げると感覚が順応し、濃さではなく変化を報告する
- **費用**：結合の強さの合計に維持費（0.001/単位/秒）、信号の活動量に活動費（0.004/単位/秒）。重みがすべて 0 なら費用も挙動への影響も 0（テストで確認）
- **切断対照**：`numb`（味覚を切る）。神経の内部状態は保存・復元の対象
- 従来の全身の脳（入力 5・出力 3）と関節の振動子は残してある

- これは「手で設計した 5 通りが駄目だった」であって、「どんな回路も得にならない」ではない

#### 判定の分け方（ユーザー、2026-11-25）
神経回路が**行動に影響していること**と、その影響が**淘汰上有利であること**は別に判定する。採食だけで評価しない。
- 行動：自力移動、直進度（正味の移動 ÷ 道のり）、旋回の頻度、繊毛の活動量、神経の活動量
- 結果：口からの摂取、総収入、生存、卵への投資。幼体の生存率は、出生を許した試験で別に測る
- 判定は切断対照（餌の方向／味覚）との比較で行い、世界ごとの範囲が重ならない差だけを「変わった」とする（`tools/alife2-ablate.js`）
- ありうる結論は四つ：行動も結果も変わらない（使っていない）／行動だけ変わる（使っているが損得なし）／両方変わり得をしている／両方変わり損をしている

個体・系統の単位で調べる（ユーザー、2026-11-25）：進化の最初の兆候は集団平均ではなく少数の個体に現れる。400 匹のうち 5 匹だけが感覚を使い始めても、平均では埋もれる。

- `tools/alife2-individuals.js`：生きている遺伝子のうち、感覚が効果器につながっているものを 1 匹だけでも候補にし、その遺伝子の複製で切断対照を行う。差が出たら (1) 単独・別の世界で再現するか (2) 祖先の遺伝子を古い順に同じ検査にかけ、どこで効果が始まるか (3) 生きている子孫の遺伝子にも効果があるか、まで調べる
- ここまで通れば、その神経機能は自然進化で獲得されたと言える。1 匹でも見つかれば大きな進展

仮説（ユーザー、2026-11-25）：**役に立たない神経回路の蓄積が、後の機能獲得の土台になりうる。** 有用な回路が一度の変異で完成する必要はなく、機能を持たない結合が蓄積し、後の変異で初めて意味のある回路になるかもしれない。したがって神経の費用を安易に上げない（無用な回路を厳しく淘汰しすぎると、途中段階まで消える）。神経系の複雑化と機能の獲得は別々に記録する。

目的：神経機能の進化を阻んでいるのが、回路の表現能力なのか、進化経路なのか、環境の選択圧なのかを切り分ける。実装する場合も現行の世界とは別の実験条件にする。

実施する場合の注意（Claude）：
- 重みを遺伝子として直接持たせると、体節あたり数百の遺伝子になる。変異のうち意味のあるものの割合が大きく下がるので、表現能力を上げたのに進化しない、という結果が「符号化の悪さ」のせいで出うる。身体と同じく間接的な符号化が要る
- 費用の付け方（結合の強さと活動量に比例）を現行と揃えないと、比較にならない
- 読み方を先に決める：この条件でも機能が進化しなければ、障壁は表現能力ではない（経路か選択圧）。進化すれば、現行の回路構造が狭すぎたことになる。どちらの結果にも意味がある
- 未学習で始めても、「進化が調整できる自由度」を一気に与える点は現行と違う。出てきた機能を「自然発生した知能」とは呼ばない

神経系の生成文法に持たせたい能力（将来の設計方針。現在の実装で可能になったものではない）：神経細胞の複製と分化／結合の生成と消失／離れた器官への信号伝達／再帰結合による内部状態の保持／可塑性による生涯中の変化／身体の位置や成熟段階による神経の発現変化。
脳という器官を最初から定義しない。局所の回路が増え、その一部が情報処理に特化し、結果として脳と呼べる構造が形成されるのが理想。

#### 設計案：体節ごとの「粒の感覚」（未実装。進化試験の結果を見てから着手）
目的：利益が確認できている生活（浅瀬で点在する餌を食べ歩く、外洋で餌に向かう）への途中段階を、体節単位で作る。
- 各体節が、自分の近く（体節の半径＋届く距離。届く距離は神経組織の量で決まる）にある粒の量を 1 つの数として感じる。**方向は与えない**
- 回路への入力に 1 つ加える（重み `nG`）。順応（`adapt`）は溶存栄養の感覚と共通
- 方向の情報は身体の形から生じる：左右に体節を持つ身体は左右の差を使え、単体節は時間変化しか使えない。どちらを使うかは決めない
- 既存の全身の脳が受け取っている「餌の方向」は、そのまま残す。局所の感覚がそれより安く同じ役を果たすなら、淘汰がそちらを選ぶはず
- 導入前に：人工個体で、浅瀬の食べ歩きが「粒の感覚だけ」で黒字になるか、感覚を切った対照と比べて確かめる。ならなければ入れても足場にならない
- 切断対照のスイッチを同時に用意する

### 設計の記録：感覚器を「向きを持つ局所受容器」に揃える（2026-11-26、未実装）

ユーザーの指摘：いまの眼は個体全体の感知範囲を広げるだけなので、何万世代回しても複眼や像の認識にはならない。他の器官も含め、可能性は残しておきたい。

**現状（コードで確認）**
- 眼：身体の中で最大の眼ひとつだけが、個体全体の感知半径を決める（`alife2-organs.js` の `o.eye` と `o.sense`）。数・位置・向きは結果に影響しない。
- 方向：「餌が前」「餌が左」は世界側が計算して全身の脳に渡している。方向を計算しているのは身体ではない。
- したがって変異が触れるのは半径の数字だけで、複眼も像も遺伝子では表現できない。構造上の行き止まり。
- 化学感覚だけは体節ごとの受容器で、身体の形が感覚の中身を決める。こちらは行き止まりではない。

**原則**
器官は「その体節の位置で、局所的な物理量を一つ測るか、一つ出すか」だけをする。方向・距離・対象の種類といった意味づけは世界が与えず、身体の配置と神経回路から生じさせる。

**眼の設計案**
- 眼組織を持つ体節は、その体節の表面の向きを中心に、ある角度幅で入る光の量を一つの数として受け取る。
- 角度幅と感度は眼組織の量と体節の形で決まる。狭く深いほど方向が絞れるが暗くなる。
- 自分の身体と他個体は光を遮る。
- 値はその体節の局所回路に入る。全身の脳へは直接渡さない。
- 新しい遺伝子は足さない。反復・対称・関節という既存の文法だけで、片眼（明暗）、対の眼（左右差）、反復体節上の列（粗い像）、関節の先の眼（走査）、適応回路との組み合わせ（動きの検出）が表現できる。
- 旧方式はオプションで残し、保存済みの世界から旧方式・新方式で分岐比較できるようにする。

**分かっている限界**
- 像の認識まで届く保証は無い。受容器の列を使う側（局所回路と 3×5 の脳）が足りない可能性が高く、神経の生成文法が律速になると予測する。
- いま光源は餌の粒しか無い。他個体・捕食者・影が見える対象にならないと、像には淘汰圧がかからない。
- 計算費用は 眼の数 × 視野内の物体数 で増える。速度は実測が要る。

**同じ行き止まりを持つ器官**
- 全身の脳の入力（餌が前／左）：眼を直してもここが残ると近道になる。最終的には局所感覚だけにする。
- 口：開口の大きさで食べられる粒が決まるだけ。接触と力で定義し直せば、噛む・掴む・他個体を食う余地が開く（捕食専用の遺伝子は作らない、という合意と同じ方向）。
- 装甲：維持費はあるが、守る相手がいないので機能が無い。
- 触覚・自己受容：接触や関節角を感じる受容器が無い。歩行や把持の制御が進化しにくい。

**検証の手順（合意済みの規則どおり）**
1. 人工個体（片眼・両眼・眼の列）を作り、切断対照で「両眼のほうが餌に寄れる」が成り立つかを測る。
2. 成り立ったら、保存済みの世界から旧方式・新方式で分岐させて比較する。
3. 眼の維持費（0.10）を含め、費用と環境は動かさない。

**予測（結果の前に固定、Claude）**
- 人工の両眼個体が切断対照より採食で上回る：70%
- 自然進化で 100 世代以内に対の眼が使われる：20%
- 眼の列が出る：5% 未満

**着手の時期**：沿岸 4 世界の 30000 秒延長の採点が済んでから。

### 他個体の感知：身体が漏らす物質と、体節ごとの嗅覚（v2.0.20、世界の選択肢 `scent: 1`、既定は切）

ユーザーの要望「せめて他の個体認識をいれたい」に対する実装。上の原則（局所の物理量を一つ測るだけ。意味は与えない）に従う。

**仕組み**
- 生きている身体は、安静時代謝に比例して 2 種類の物質 A・B を水に漏らす。配分は遺伝子 `odor`（0〜1、A の割合）。遺伝するので血縁は似た匂いになる。
- 物質は溶存栄養と同じ格子で拡散し、毎秒 5% 消える（`stepScent`）。
- 配線のある体節は、自分の位置の A と B の量をそれぞれ感じる。遺伝子 `sA` `sB` が局所回路への重み。読み方は味覚と同じ（量そのもの／`adapt` に応じて変化分）。
- 世界は「他個体」「血縁」「敵」といった意味を一切渡さない。自分の匂いも区別せず混ざる。
- 切断対照：`anosmic`（世界全体）と `o.anosmic`（個体）。
- 保存・復元は匂いの場と受容器の状態まで含む（テストで一致を確認）。

**既存の世界への影響（確認済み）**
- `scent: 0` の世界では `sA` `sB` `odor` は変異せず、乱数も消費しない。標準・沿岸の両方で、6000 ステップ後の状態が変更前と完全に一致した。走行中の延長実験とその解析には影響しない。

**人工個体での検証（`tools/alife2-scent-assay.js`、200 秒 × 4 世界、`docs/alife2/evo/scent-assay-artificial-200s.txt`）**
予測は事前に固定していない。以下は探索的な結果として扱う。

| 条件（密集：3 か所に 12 匹ずつ） | 収支 [範囲] | 生存 | 移動 | 最近接の他個体まで |
|---|---|---|---|---|
| 繊毛・回路なし | 0.029 [0.027〜0.031] | 90% | 72.0 | 8.6 |
| 匂うと泳ぎ、薄いと休む | 0.019 [0.016〜0.023] | 87% | 40.8 | 9.4 [9.2〜9.7] |
| 同じ回路・嗅覚を切断 | −0.009 [−0.015〜0.007] | 49% | 7.6 | 2.2 [1.7〜2.5] |

- 行動：嗅覚の有無で、移動と個体間距離は範囲が重ならずに変わった。**他個体の存在が行動を変える経路は成立している。**
- 利益：切断対照には勝つが、何も感じずに泳ぎ続ける個体（0.029）には密集条件で負ける。まばらな条件では 0.039 対 0.035 で範囲が重なり、生存は 99% 対 89%。**「感じることの利益」は示せていない。**
- 「匂いが増えると曲がる」は密集で切断対照より悪い（収支 −0.033 対 0.012）。

**系統の区別（A を出す配線個体 18 ＋ B を出す動かない個体 18 を混ぜる）**
- 「B が匂うと泳ぎ、A だと休む」は移動が 34.9 [32.4〜38.2]、切断は 69.3 [63.1〜76.1]。行動は変わった。
- しかし他系統までの距離は 27.0 [24.2〜29.6] 対 33.0 [23.1〜40.0] で範囲が重なり、同系統に集まる効果も明確でない。**位置の結果としての「見分け」は検出できなかった。**
- 受容器の段階では区別できている（テスト：B の群れの中で `sB` 回路は +0.28、切断は −1.00）。
- この試験は 200 秒で全員が散ってしまい、区別が効く場面が短い。試験の設計が弱い可能性がある。

**未実施**
- 匂いのある世界での進化試験（複数シード、切断対照つき）。
- 匂いが利益になる場面は、いまの世界では混雑の回避しか無い。捕食・交配が入るまで、系統の区別には淘汰圧がほとんどかからないと予測する。
- 視覚による他個体の感知（上の眼の設計）は未着手。

## 6. 未解決の問題（正直な一覧）

1. **動く生活が勝てない。** 粒が勝手に流れてくる限り、待つ方が安い。必要なのは「動かないと届かない資源」と「動かないと死ぬ理由」：粒の沈降・拡散を弱めて集中域を速く動かす、捕食（固着者は食われる）、底面の固定餌を食い尽くす局所枯渇
2. **大型化が成立しない。** 維持費 ∝ 体積、摂取 ∝ 口幅×速度。世界のエネルギー流量も小さく、体積45の個体は全流量でも9匹しか養えない。相対成長（深部組織の低代謝、輸送網）と世界の規模の両方を設計し直す必要がある
3. **感覚が粗い。** 眼は「飲み込める粒の方向」を返すだけ。視野・距離・他個体の識別は無い。脳は 3×5 の線形写像
4. 幼体の口が小さすぎて親と同じ餌を食えない（出生時の大きさの遺伝子で回避可能だが、進化はまだ使っていない）
5. 有性生殖・捕食・死骸以外の個体間相互作用が無い
6. 世代が遅い：6000秒で16〜18世代、1シード約12〜14分。長期試験には高速化が必要（動く関節の無い身体は物理を省略済み）
7. 世界の体節上限は 64（計算量のため。実験室は 160）
8. 身体の自己衝突が無い（脚どうしが重なる）。関節可動域だけで防いでいる
9. 一部の変異体で関節が可動域を大きく超えることがある（長い体節＋強い力）
10. 平面2次元。放射相称動物本来の軸方向遊泳は表現できない。尾鰭は「縦に厚い板」として物理的には正しいが、上から見ると細い
11. GPU 描画はヘッドレス Chromium（ソフトウェア WebGL）での動作と画像しか確認していない。**実機 GPU での速度は未測定。** 現状は1体ごとに全画面を全体節で評価するので、多数個体の生態系では個体ごとの矩形描画に変える必要がある
12. 写実性：外皮の屈折、被写界深度、器官の立体感はまだ無い。目標画像の品質には届いていない
13. 放射型は8回の変異で約30%が体節数1/4未満に崩れる。他は0〜9%
14. 物理定数（筋応力、抵抗係数）は任意単位。現実の値との対応は取っていない
15. 旧 ALIFE 23 の生態系・神経回路・学習・営巣との接続は未着手
